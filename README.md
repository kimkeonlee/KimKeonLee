## About Me

저는 React Native와 TypeScript를 중심으로 모바일/웹 서비스의 사용자 경험을 구현하는 프론트엔드 개발자입니다.

보험·핀테크 도메인에서 복잡한 정책, 입력 흐름, 사용자 행동 데이터를 다루며  
“기능을 만드는 것”보다 **사용자가 실제로 문제를 해결할 수 있는 흐름을 만드는 것**에 관심을 가져왔습니다.

최근에는 Java와 Spring Boot를 학습하며 API, 데이터베이스, 인증 흐름까지 이해하는 개발자로 확장하고 있습니다.

## How I Work

| Principle | Description |
| :--- | :--- |
| **Problem First** | 화면을 만들기 전에 사용자가 어디서 막히는지, 어떤 문제를 해결해야 하는지 먼저 정의합니다. |

| **Domain Understanding** | 보험·금융처럼 복잡한 도메인의 정책과 용어를 사용자에게 이해 가능한 화면 흐름으로 바꿉니다. |
| **Collaboration** | 기획, 디자인, 백엔드, 운영 관점에서 발생할 수 있는 문제를 미리 공유하고 문서화하려고 합니다. |

## Featured Work

### 1. 보험 문서 디지털 전환

> 오프라인 중심의 보험 서류 작성 흐름을 모바일 환경에서 처리할 수 있도록 전환한 프로젝트입니다.

| | |
| :--- | :--- |
| **Problem** | 사용자가 오프라인 서류를 직접 작성하거나 제출해야 해 입력 누락, 작성 오류, 처리 지연이 발생할 수 있었습니다. |
| **Approach** | 입력 단계를 화면 단위로 나누고, 필수값 검증과 사용자 안내 문구를 개선하여 작성 흐름을 단순화했습니다. |
| **My Role** | React Native 기반 화면 구현, 입력 폼 구조 설계, API 연동, 사용자 플로우 개선 |
| **Tech** | React Native, TypeScript, Form Validation, API Integration |
| **Impact** | 사용자가 문서 작성 과정을 더 명확하게 이해하고, 운영 관점에서도 처리 흐름을 관리하기 쉬운 구조로 개선했습니다. |

| | |
| :--- | :--- |

| **Approach** | Amplitude 이벤트를 설계하고, 사용자 행동 데이터를 관찰하여 병목 구간을 확인했습니다. |
| **My Role** | 이벤트 설계, 화면 개선, 문구/CTA 조정, 개선 후 데이터 확인 |
| **Tech** | React, React Native, TypeScript, Amplitude |
| **Impact** | 감에 의존하지 않고 데이터 기반으로 사용자 흐름을 개선하는 경험을 쌓았습니다. |
